Genealogy workflows for tracing real families. Each guide answers a single "I want to..." question with a setup checklist, numbered steps, and pointers to the relevant wiki reference.

## Available now

- [I want to add my first person from scratch](add-first-person-manually/) — Create your first person note manually, then add relationships when you're ready. *Easy · ~5 min*
- [I want to import a GEDCOM file and clean up the result](import-gedcom-and-cleanup/) — Import a GEDCOM with the Data Quality Preview, normalize place-name variants, and triage duplicates against your existing tree. *Medium · ~30+ min*
- [I want to set up per-fact source citations](set-up-source-tracking/) — Track which sources support each fact about a person, with coverage scoring across your tree. *Medium · ~15 min*
